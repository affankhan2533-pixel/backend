# Dr. Siulik's Dental Care - Backend API

Express.js REST API service for Dr. Siulik's Dental Care platform.

## Features
- **Appointments API**: Manage appointment requests and scheduling
- **Clinic Info API**: Endpoints for clinic credentials, services, and working hours
- **Contact API**: Patient inquiry and feedback handling
- **Reviews API**: Verified reviews and ratings

## Setup & Running Locally

1. Install dependencies:
```bash
npm install
```

2. Configure environment:
Copy `.env.example` to `.env` and fill in your variables:
```bash
cp .env.example .env
```

3. Run in development:
```bash
npm run dev
```

4. Run in production:
```bash
npm start
```
